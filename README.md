# An anniversary evening

A mobile-friendly anniversary dinner comparison near Clermont, FL: Chef's Table at the Edgewater + The Attic Door (Winter Garden), Matthew's Steakhouse + a Plant Street walk (Winter Garden), and Huarike + Back 40 Wine Co (downtown Clermont).

Static HTML/CSS, no analytics, no forms, no build dependencies. Target date is around Tuesday, December 22, 2026. No bookings are implied. Public content excludes residential addresses and private family logistics. The requirements live in `REQUIREMENTS.md`.
