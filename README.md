# An anniversary evening

A mobile-friendly Central Florida anniversary dinner comparison: Matthew’s + Pilars, Kres + Mathers, and Christner’s + its piano bar.

Static HTML/CSS, no analytics, no forms, no build dependencies. Candidate evenings: December 27, 29, and 30, 2026. No bookings implied. Public content excludes residential addresses and private family logistics.

## Sources and photographs

Restaurant Google ratings and route estimates were checked during the planning conversation. They are snapshots, not future traffic forecasts. Menu, availability and holiday schedule checks remain necessary before booking.
